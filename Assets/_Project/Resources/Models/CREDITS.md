## Packs Used

- **KayKit Character Pack: Adventurers** — used for player, apprentice, customers
  - Source: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
- **KayKit Dungeon Remastered** — used for environment props, furniture, potion bottles
  - Source: https://github.com/KayKit-Game-Assets/KayKit-Dungeon-Remastered-1.0
- **KayKit Medieval Hexagon Pack** — used for forest decor (trees, stumps) and hut/cottage building
  - Source: https://github.com/KayKit-Game-Assets/KayKit-Medieval-Hexagon-Pack-1.0
  - Files were converted from `.gltf` (with separate `.bin` + atlas `.png`) into self-contained `.glb` via `gltf-pipeline`.
